# Battleship---Object-Oriented-Programming
Description - 
Our final game will be a single human vs. bot opponent battleship game. The human player will manually place ships, and the bot will randomly place them. Once ships are placed, the human and bot will take turns firing on the enemy grid, once again human choosing manually and bot randomly. Once one has sunk all ships, the game ends with a win/loss message.

## Running
- Start the server: ./gradlew bootRun   (then visit http://localhost:8080)
- Run tests:        ./gradlew test
  Or use the Gradle tool window in IntelliJ.

Current Assumptions:
- board is fixed at 10x10
- used normal battleship ships
